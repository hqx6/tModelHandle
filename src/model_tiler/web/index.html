通用模型切片

将模型转换为可定位、可分块加载的 3D Tiles。

01 输入模型

尚未选择文件

02 空间定位

默认位置为天安门附近，请按模型实际位置调整。

03 切片策略

输出 3D Tiles 1.0，包含构件 ID 与属性。化简模式保留最高精度层；纹理和接缝可能限制化简比例。

04 模型与材质设置

本地预览显示最高精度几何与基础颜色；纹理、压缩和 LOD 效果请在 Cesium 地球预览中检查。
调整输出原点不会改变模型在地球上的位置。 0 表示不限制。达到深度上限或仅剩一个三角形时可能超限，结果会列出提示。

05 压缩与实例优化

位置量化位数越高精度越高；构件 ID、UV 和法线保留。0 关闭；至少 2 个相同构件时输出 I3DM。支持平移、旋转和均匀缩放，未匹配构件保留普通网格。

06 复用资源库

选择历史资源库可跳过导入。编码、上轴、比例与绕向沿用缓存；材质、原点、属性和分块参数可重新设置。
